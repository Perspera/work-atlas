# 单量与作业进度看板

把原来「一个人维护 Excel、靠公式汇总」的日报，换成一套**局域网内多人同时观看、需登录、可拖拽自定义**的作业看板系统。

- 数据自动从 **WMS「发运表」** 与 **TMS「运输单状态」** 的下载文件读取，历史自动积累
- 当天要发运的**波次在系统里登记**（增/改/删），不再维护 Excel 的波次登记表
- **作业进度**（波次生成 → 拣货 → 复核 → 出库）与**单量**（订单组 / 行数 / 金额）实时看
- 权限**逐项授权**：用户组 × 页面/组件/动作/敏感字段 × 数据范围
- 看板**拖拽自定义**：组件、维度、指标、筛选自己搭配，保存成自己的布局

## 一、三分钟启动

1. 双击 **`启动看板.bat`**：黑色窗口里出现中文横幅后，会**自动等服务就绪再打开浏览器**（不再出现"打开太早、无法连接"）
2. 交付时已初始化管理员账号：**admin / Admin12345**（本地开发库已改密为 `admin123`，全新安装仍是 `Admin12345`，登录后请第一时间在右上角「修改密码」改掉；默认口令账号会被要求先改密，接口返回 428）
3. 用管理员登录 → 左侧「数据源」页确认目录可达 → 把 WMS/TMS 下载文件丢进数据目录（出库文件可在「出库归档」页查询）

> 窗口不要关：关掉窗口 = 停服务。如果服务已经在跑，再双击脚本只会打开浏览器，不会重复起进程。

局域网同事用浏览器打开：**http://192.168.200.159:8787**（本机 IP，换机器就是那台机器的 IP）

需要开机自启：`安装开机自启.ps1` 右键「以管理员身份运行」（同时开放防火墙 8787 端口）。

> 想彻底重新初始化（清空所有账号与业务数据）：停服务 → 删除 `data/dashboard.db` → 重新启动，会进入初始化向导。
> **数据源只有一个：`Z:\单据登记\测试`**（`config.json` 的 `sample_dirs` 已置空，样本数据已清理）。

## 二、数据怎么进来

### 目录约定
```
Z:\单据登记\测试\                ← 数据目录（config.json 可改）
    任意文件名.xlsx / .xlsm / .csv   ← WMS「发运表」导出
    任意文件名.xlsx / .xlsm / .csv   ← TMS「运输单状态」导出
    dealers.xlsx                    ← 经销商映射；sheet「dealers」全称/简称/区域/承运商，sheet「动力电池」地址映射
```

- **不用改名、不用删旧文件**：系统按表头识别，不是按文件名。
  - 含 `订单日期 / 波次号 / 订单组号 / 备件编码 / 出库时间` → 认成发运表
  - 含 `外部单号（波次号） / 状态 / 承运商 / 订单组号` → 认成运输单状态
  - 含 `全称 / 简称 / 区域 / 承运商` → 认成普通经销商映射
  - 含 `经销商 / 单据类型 / 承运商 / 地址` → 认成动力电池地址映射
- **自动更新**：每 60 秒扫一次目录；同一天的导出重新下载覆盖，会就地更新进度（拣货/复核/出库时间、状态），不会重复累计。
- **识别不了的文件不会让系统坏掉**：「数据源」页会红字列出缺了哪些列。
- 共享盘临时断开时，看板继续显示上一次的数据，并在「数据源」页提示不可达。

### 一次性的经销商映射
「区域 / 承运商线路」来自经销商主数据。系统先按**全称**匹配，匹配不到再按**简称**匹配（全称优先；简称重名按全称字典序取一条）。仍未命中的会进「未映射」分类——账不会丢，但分类不准。

在「数据源 → 未映射经销商」里逐个「补映射」，或用 `dealers.xlsx` 批量导入（sheet「dealers」：全称/简称/区域/承运商；sheet「动力电池」：经销商/库区/单据类型/是否免运费/区域/承运商/送达城市/地址）。这部分做完，线路口径就完整了。

## 三、每天怎么用

| 时间 | 操作 |
|---|---|
| 早上 | 「波次登记」→ 显示候选波次 → 勾选当天要发的波次 → 一键登记（也可粘贴波次号）。**发运表里还没有的波次也能登记，标「待数据」，文件到了自动补全** |
| 白天 | 「订单组登记」核对/修正订单组的区域、承运商、指派；「今日总览 / 作业进度 / 人工作业量」看进度，页面每 30～60 秒自动更新 |
| 全天 | 大屏常开：顶栏「大屏」→ 自动轮播各看板；超时线路会滚动红条 + 提示音 |
| 交接 | 「订单组登记 → 存档今日」把当天台账按日期存档；「今日总览 → 打印单量表」按现行版式打印签字 |

- 登记错了：波次行右侧「编辑」（改备注/改波次指派）或「删除」（软删除，审计可追溯）。
- 订单组要改：在「订单组登记」里点该行「编辑」，可改 **承运商 / 区域 / 指派 / 备注**，或取消「计入本波次」把它**移出**（灰显保留，可随时恢复/恢复默认）。
- 两个人在改同一条：后保存的人会收到「…刚被别人修改，请刷新后再试」。

### 看板总台：一个地方管所有看板

「看板总台」页把所有看板集中成卡片列表：

- **导航页看板**（今日总览 / 作业进度 / 单量分析 / 人工作业量 / 趋势）每张卡片显示：当前生效版本（公共 vN / 我的 vN）、组件数、**布局缩略图**。
- 卡片操作：
  - **编辑** → 进入该看板的编辑器：**自由摆放**（拖到哪放哪，不会自动挤动别的组件），拖右下角改大小、点 ⚙ 改数据、从组件库添加/删除；支持**撤销/重做**（Ctrl+Z / Ctrl+Shift+Z）与「**整理布局**」手动紧凑
  - 编辑期间**页面不再自动刷新**（实时推送会被挂起），不会出现"编辑到一半被刷新打断"；退出编辑/回到其他页面后自动恢复实时刷新
  - **拖动放大/缩小组件后内容按新尺寸重绘**：图表宽高、KPI 字号、表格布局都会跟着变（拖动中显示占位框，松手生效）
  - **发布** → 把当前布局发布给所有人（导航页 = 更新该页；专题 = 发布为公共看板）
  - **复制** → 把该布局复制成一个新专题看板（页面看板也能复制成专题，改坏不影响原页）
  - **加入/移出大屏** → 直接改大屏轮播清单
  - **恢复默认**（有个人布局时）/ **删除**（自己的专题）
- 每个导航页自己右上角仍有「编辑布局」，和总台编辑的是同一份布局：编辑即存为**我的布局**，管理员「发布为全员默认」后所有人看到新样式；已自定义的人保留自己的，页面顶部提示可切换。
- 「新建专题看板」从空白画布开始；管理员还能一键清理**孤儿看板**（所属账号已删除）。

### KPI 单位与配色

- KPI 数字：页面约 50–56px、大屏 64–76px，字重 700；金额/长数字自动降一档避免截断。
- 单位自动带在数字后：行数「行」、人数「人」、金额「万元」、比例「%」、时长「h」、人效「行/小时」。
- 默认统一品牌蓝，不再按指标自动红/绿/橙；在组件配置 →「配色」中可选 **默认 / 马卡龙 / 多巴胺** 色系和具体色块，图表会按所选色系给系列上色。
- 在总览点击「待组波行数/待组波金额」可打开「待组波明细」：只看所选订单日期中**波次号为空**的行。

### 大屏模式（滚动展示）

- 顶栏「大屏」进入 `/screen`：隐藏导航，按管理员勾选的清单**整屏轮播**（默认 5 个页面、15 秒/页，可改）。
- **大屏会自动分页**：一个看板如果组件较多，会按行拆成多页（标题显示「第 i/N 页」，底部圆点=总页数），保证每页完整落在屏幕内，不再出现“只显示半边/下面看不到”。
- **KPI 卡在大屏上放大**：数字 48–64px 粗体、单层卡片、内容居中；表格/图表字号也按大屏比例放大。
- **大屏日期与数据一致**：默认显示**最近已登记业务日**（今天没有登记时不会显示空白）；顶部日期与所有组件取数同一天。
- 顶栏显示看板名、业务日期、时钟；超时/临近线路以**红条/黄条滚动**提示；「设置」里可配播放清单与间隔（按页轮播）。
- 键盘：`←/→` 切换、空格暂停、`Esc` 退出；底部圆点可点。
- **声音**：浏览器要求先有一次点击才允许播放，进入后点「启用声音」即可（出现新的超时线路会响）。
- 建议给大屏建一个**只读专用账号**并勾「开机自启」，避免会话过期（页面每 5 分钟自动续期）。

### 预警中心

- 「预警中心」按线路配 **截止时间**（默认：上午线 12:00、下午线 17:00、顺丰/自提 16:00）和**负责人**（可多个账号）。
- 判定：该线路当天已登记行数的**复核完成率 = 100%** 即完成；未完成时：
  - 距截止 **30 分钟**提醒 1 次；
  - **超时后每 15 分钟**重复提醒，直到完成或换天（分钟数可在数据库 meta 调）。
- 通知去哪：负责人账号的**站内消息**（右上角铃铛红点 + 未读列表）+ **大屏红条**；没配负责人时兜底发给管理员。
- 消息可单条/全部标记已读；同一线路同一时间桶不会重复刷屏。

### 人工作业量（按作业日期，拣货/复核分开）

- **日期归属 = 作业时间日期**：拣货看 `拣货时间` 的日期、复核看 `复核时间` 的日期。同一波次跨天时，行会按实际作业日期落到不同天。
- **拣货与复核分开计数**：拣货行数、复核行数各自统计（不再合成"作业行次"），人数也分开（拣货人数 / 复核人数）。
- **人效 = 行数 ÷ 有效作业工时**（行/人·小时）：
  - 有效作业工时 = 该人该工种当天**相邻作业时间点的间隔累加**：间隔 ≤ 阈值（默认 30 分钟，可调）才计入；超过阈值视为休息不计
  - 计入的区间再**扣除全局休息时段**（默认 12:00-13:00 午休）的重叠分钟
  - 只有 1 个时间点无法推断时长 → 人效显示「-」
  - 例：11-02 拣货 4,824 行 / 96.26h ≈ **50.1 行/小时**；复核 4,664 行 / 80.11h ≈ **58.2 行/小时**（旧口径按"有记录的小时数"是 30.5 / 38.2）
- **小时趋势**：每小时拣货行数 / 复核行数 / 参与人数（只做趋势图，人效仍按天算）。
- **人工校正**：页面下方「人员明细与工时校正」可分别填某人的**拣货工时 / 复核工时**（覆盖自动有效小时，标「已校正」，可「恢复自动」），写审计。
- **作业设置**（右上按钮，需 `action.labor.settings`）：维护**相邻作业间隔阈值**与**全局休息时段**；保存后实时页立即按新口径算。历史存档不会自动变，弹窗里可「按新口径重新存档全部日期」。
- **实时 / 存档**：右上「实时 / 存档」切换；「存档本日」按作业日期冻结当天汇总，跨天会自动补档（只补缺），也可「重新存档」覆盖。
- 注意：人员字段从 **2026-11-03 这次导入** 才开始采集；更早日期要有人员数据，需把当时的导出文件放回 `Z:\单据登记\测试` 重新扫描。

### v16 数据口径说明

- 发运明细按 `wms_no + line_no` 唯一；重导后订单组号变化会更新原行，不产生“空组 + 正式组”重复行；
- 订单组登记、订单组数、已登记行数/金额只统计**有最终订单组号**的行；未编号行仍计入「系统订单量/金额」；
- 「已登记行数/金额」按**波次登记日归属**：只要波次在所选业务日登记，波次内其它订单日期的行也计入；系统订单量/金额仍按订单日期统计；
- 今日总览按所选 `订单日期` 取数，不再混入已登记波次里其它日期的行；
- 数据源文件台账默认显示全部文件版本，并显示每个文件的**实际内容日期**；文件名日期与内容日期不一致会标记「日期不一致」；
- 同一业务日期以最新完整导出为准，旧版本中已不存在的行会在扫描时清理；
- 系统订单量/金额、已登记行数/金额四张卡默认显示「较上日」环比。

### 数据源页的「WMS 自动下载」面板

数据源页现在直接提供 WMS 自动下载配置，不需要命令行：

- 编辑 WMS 地址、查询日期（今天/昨天/固定/相对）、执行方式（每天时间点或 08:00–21:00 每 10 分钟）、下载目录；
- 「保存配置」「立即下载」「启用/更新定时任务」「暂停」「移除任务」「查看日志」；
- 面板显示定时任务状态、下次运行、最近一次成功/失败和最近导入文件；
- 配置写入 `tools/wms_download/wms.config.json`，保留页面选择器/登录/导出设置；不保存 WMS 密码（当前使用 aTrust SSO / 已登录会话）；
- 立即下载会启动后台 Node 进程，完成后自动触发扫描导入；定时任务仍由 Windows 任务计划执行。

> 详细说明见 [tools/wms_download/README.md](tools/wms_download/README.md)。

### 外部 WMS 自动下载（可选）

如果 WMS 只能网页登录、手工按日期导出，可用 `tools/wms_download/` 的浏览器自动化：

- Chrome + Puppeteer 自动登录、进入查询页、填日期、查询、下载，并校验表头后放入 `Z:\单据登记\测试`；
- Windows 任务计划每天定时执行；支持昨天/今天/指定日期；
- 账号密码放本机 `secrets.local.json`，不写入代码/日志；
- 首次需要填 WMS 地址/页面选择器，详见 [tools/wms_download/README.md](tools/wms_download/README.md)。

### 自动归档与归档查询（数据源页）

- **自动归档已开启**：每次扫描如果发现文件有**新增行或内容变更**（状态/拣货/复核/出库时间/回传状态等变了），系统会把**受影响日期**的归档覆盖成最新：
  - 订单组登记：按**业务日**（受影响波次登记的那天）整日覆盖
  - 人工作业量：按**作业日期**（新增/变更行的拣货、复核日期）整日覆盖
  - 今天也会自动归档并在有新数据时覆盖；没新增/变更的日期不动
- **数据源页 →「每日归档」**：订单组归档 / 人效归档两张清单，可**查看明细**（订单组按台账字段、人效按人×工种）、**按日导出**或**按日期区间批量导出 CSV**。
- 手工入口仍保留：「订单组登记 → 存档今日/重新存档」「人工作业量 → 存档本日/重新存档」。

### 出库归档页（新）

- 只归档 **【出库】出库流程节点时间跟踪(配送中心)** 文件：扫描读取到的**表头 + 全部数据行**保存为归档数据；文件内容变化时覆盖同一份归档，不按日期/文件名堆积版本。
- 独立页面「出库归档」：
  - 按文件表头列筛选（最多 3 个条件：包含/等于）；
  - 选择日期列（订单日期/订单生成日期/拣货时间/复核时间/出库时间等）做**区间查询**；
  - 每页固定 **50 条**，分页显示总数/页数；
  - **导出当前筛选 CSV**（无筛选则导出全部）；宽表横向滚动。
- 旧“扫描文件归档”（所有文件、历史版本台账）已下线；TMS/经销商不再归档，旧归档记录在升级时清理，避免台账越积越多。
- 存储位置：`看板系统/data/outbound_archive/rows.jsonl.gz`（只保存行数据快照与表头，不保存原始表格）。

### 未映射经销商：导出 + 批量更新

- 数据源页「未映射经销商」面板：**导出未映射 CSV**（列：全称/简称/区域/承运商/线路，另附行数、金额供参考），填好后用**批量导入更新**上传。
- 导入规则：全称必须与发运表里的「交货地/经销商全称」一致；**已存在的映射只覆盖非空字段**（空着保持原值），不存在则新增；返回“新增 / 更新 / 跳过”数量。
- 权限：`action.dealers.manage`；导入后单量分析的区域/线路维度会立即按新映射生效。

### 动力电池登记页

- 从发运明细自动列出含动力电池备件的订单组；
- 一个订单组 + 一个备件编码一行，经销商按订单组匹配；
- 显示备件编码和备件名称；数量/金额只汇总该组该编码的动力电池行；
- 地址/库区/单据类型/是否免运费/区域/承运商/送达城市从 `dealers.xlsx` 的「动力电池」sheet 自动带出；
- 人工确认「登记」后保留已登记状态，不手工改数量金额；
- 可上传动力电池备件编码表（至少包含「备件编码」列，可选「备件名称」）；未上传时暂按 `动力电池总成` 名称匹配；
- 经销商显示简称，未匹配时可在表格内直接录入地址/简称，保存后后续自动匹配；
- 登记按**实际登记日期**归属：订单日期只用于找候选；昨天订单今天确认，登记日期是今天；
- 支持每日存档，存档快照按实际登记日期、关键字、状态筛选；
- 今日总览有「今日动力电池登记」表格组件，含拣货/复核行数、汇总行，未完成行标红；
- 表格组件在「看板总台」可控制显示字段、拖拽列宽/列顺序，配置随布局发布；
- 动力电池登记页增加「当天已登记明细表」，按实际登记日期显示并带汇总行；
- 总览「超期未复核」改为可配置表格组件，只显示超过预警时间的订单组并标红；
- 导航栏已移除作业进度、趋势；
- 单量分析支持今日/本周/本月/本季度及环比、同比。

### 订单组登记页（与现行《单据登记表》同字段）

13 列 + 备注 + 操作：序号、订单组号、经销商、行数、金额(元)、库区、单据类型、是否免运费（预留）、区域、承运商、波次号、清洗、指派。
- **顺序**：默认按波次登记先后（同一波次内按行数降序），可切换「按波次号」。
- **筛选**：波次、承运商、区域、关键字、仅计入/已移出。
- **存档**：右上角「存档今日 / 重新存档」；切到「存档快照」可回看任意已存档日期（只读）。系统在**跨天**时会自动给已登记的历史业务日补档（只补缺、不覆盖）。
- 存档按业务日期各存一份：`2026-11-01` 的 5 个波次、`2026-11-02` 的 32 个波次互不影响。
- **没有订单组号的行**（WMS 导出偶尔不填）：按 WMS 单号单独成组，显示为「未编号（单号）」，避免几百行被并成一个空组。

### 业务日期怎么分（昨天 / 今天）

顶部下拉里的「业务日期」决定你**在哪一天**登记、修改和存档：

- **默认是今天**（系统当天），不是"上一次登记的日期"——这样跨天后新登记一定落到今天。
- 下拉里同时列出：**今天**、已登记过的日期、已存档的日期、有发运数据的日期，并标注「登记 N / 已存档 / 有数据 N」。
- 选到历史日期时，页面顶部出现黄色提示「当前业务日：2026-11-01（不是今天 …）」，此时新增/删除波次、改订单组、存档**都会记到那一天**；点「切回今天」或右上角「回到今天」即可回到当天。
- 页面开着跨过零点：只要没手动选过日期，系统会自动切到新的一天并提示。
- 每个日期是**独立的一份数据**：波次登记、订单组台账、存档、总览/进度指标都按业务日期隔离，互不串。

## 四、角色与权限

账号由管理员在「用户与权限」里创建，首次登录强制改密。

| 预设角色 | 能做什么 |
|---|---|
| **管理员** | 全部，包括用户/用户组/权限/数据范围/审计/经销商映射/发布全员默认/大屏配置/预警规则 |
| **登记员** | 看所有页面、登记/修改/删除波次、改订单组明细、存档、校正工时、自定义并发布自己的看板（不能改预警规则与大屏配置） |
| **只读** | 只能看（含订单组台账与存档、人工作业量、预警消息、大屏），不能改任何业务数据 |

权限是**逐项**的：约 43 个权限点，分「页面 / 组件 / 动作 / 字段与数据」四类，可以单独允许或拒绝。
例如：某人能看「单量分析」但**看不到金额**（`field.amount` 拒绝），接口响应里就不会出现金额数字，不是前端藏起来。

**数据范围**（行级过滤）可设在用户或用户组上，支持：

| 维度 | 取值示例 | 含义 |
|---|---|---|
| region | 广东 | 只看该区域数据 |
| route | 下午—广东直发线 | 只看某条线路 |
| zone | F | 只看某个库区 |
| doc_type | 常规订单出库（RDC） | 只看某类单据 |
| waves | own | 只看本人登记的波次 |

多个来源取并集；留空=不限。所有查询在服务端注入过滤，直接调接口也一样受限。

## 五、数据口径（和原来那张单量表怎么对）

| 指标 | 定义 | 与现行「单量表」 |
|---|---|---|
| 登记波次 | 当日在系统登记的波次（含还未到数据的） | 一致 |
| 订单组 | 波次覆盖的发运明细里 distinct 订单组号 | 一致 |
| 行数 | 发运明细行数 | 一致 |
| 金额 | Σ 发运表金额（看板按万元、订单组台账按元显示） | 一致 |
| 已拣 / 已复核 / 已出库 | 拣货/复核/出库时间不为空的行数 | 一致 |
| 发运状态 | 发运表状态分布 | 一致 |
| 运输单释放率 | 命中 TMS 的波次 / 已登记波次 | 一致 |
| **库区** | **取每条明细行自己的「区」** | **与表略有差异**：原表单取订单组的首个库区；本系统按行统计，各库区之和恒等于总行数 |
| 线路/承运商 | 经销商映射（全称优先、简称兜底）；`调拨出库` 强制归「省外调拨 / 顺丰速运」 | 一致 |
| 清洗 | 该波次在 TMS 里的状态（对应原表 `XLOOKUP(波次号,运输单状态!A:A,运输单状态!B:C)`） | 一致 |
| 指派 | 订单组指派 > 波次指派 > TMS 承运商；可逐组手工覆盖 | 对应原表手工填写的「指派」 |

**订单组级覆盖**（订单组登记页的编辑）按「业务日 + 订单组」生效，优先级：
`指派`：组覆盖 > 波次指派 > TMS 承运商；
`承运商`：组覆盖 > 波次指派 > 调拨规则 > 经销商映射；
`区域`：组覆盖 > 调拨规则 > 经销商映射；
「移出」的订单组不计入单量/进度/趋势，但仍在台账和存档里可见、可恢复。

超过截止时间（默认 16:00，`config.json` 的 `cutoff_time`）仍未出库的订单组，会进「超时未出库」预警清单。

### v5 新增口径

| 指标 | 定义 |
|---|---|
| 复核完成率 | 已复核行数（check_time 非空）/ 总行数（已登记波次、未移出） |
| 今日订单量 | 当天订单日期的**全部**订单组（不管有没有登记） |
| 今日已登记 | 上述订单组里，落在已登记波次内的部分 |
| 今日漏登记 | 今日订单量 − 今日已登记（明细可查） |
| 登记覆盖率 | 今日已登记行数 / 今日总行数 |
| 全链路时效 | 组级「最晚出库时间 − 最早波次生成时间」，另拆 波次→拣货 / 拣货→复核 / 复核→出库 |
| 已登记行数/金额 | 选中日期**已登记波次覆盖的全部行**（= 订单组登记台账口径，含已移出、含跨天订单） |
| 未拣货行数 | 已登记波次（业务日期）里 `拣货时间` 为空的行数 |
| 拣货完成率 | 已拣行数 / 总行数（业务日期口径，与复核完成率一致） |
| 人均每小时拣货行数 | 拣货行数 ÷ 所有人拣货有效工时（作业日期口径，= 人效页拣货人效） |
| 已复核行数 / 复核完成率 | 已复核 = `复核时间` 非空 **或** `出库时间` 非空（少数已发货行没有复核时间） |
| 未复核行数 | `复核时间` 为空 **且** `出库时间` 为空的行数（已出库不再算未复核） |
| ERP 回传 | 维度 `erp_status`（成功/未回传/失败/未记录）+ 指标：回传失败行数/金额、未回传行数/金额（按行统计） |
| ERP 明细 | 「回传失败明细」「未回传明细」按订单组展示（序号/订单组号/经销商/行数/金额/库区/单据类型/区域/承运商/波次号/清洗/指派/ERP状态/回传信息/回传时间） |
| 人工作业量 | 按**作业日期**统计；拣货/复核分开计数；人效 = 行数 ÷ 有效作业工时（相邻间隔累计、扣除休息时段），人工校正优先 |
| 未编号订单组 | 导出没填订单组号的行按 WMS 单号成组（显示「未编号（单号）」），计入单量与金额 |

> 当天登记了波次但 WMS 导出还没包含它们时，看板会显示「待数据」并提示当前导出覆盖到哪一天；文件到了自动补全，不需要重新登记。

## 六、看板总台与自定义看板

「看板总台」页管理所有看板（见第三节）：导航页看板 + 专题看板，卡片式展示，可编辑/发布/复制/加入大屏。

「新建专题看板」后进入自由画布：

1. **从模板添加**（推荐）：点「+ 从模板添加」，按业务分组挑选场景模板（今日订单量/金额、登记覆盖率、拣货/复核完成率、每小时拣货复核、线路/波次进度、人效排行、ERP 回传状态、回传失败/未回传明细、超时未复核、每日趋势），点卡片即添加到画布——模板均为完整合法配置，不需要再填表。
2. 也可以按类型添加（KPI 卡 / 柱状 / 折线 / 饼环 / 漏斗 / 表格 / 进度条 / 预警 / 文本），或在模板库底部「按类型自定义」进入配置向导。
3. **配置向导**（组件配置）：左侧选“看什么数据”（带业务说明），中间选“按什么分组 / 看什么指标”（指标按数量、比例、金额、时长分组；KPI 默认单选指标），数据集特有的筛选（如 ERP 明细的“回传失败 / 未回传”）直接给出选项，底部**实时预览**当前业务日期的条数/图形/前 3 行。
4. 拖动标题栏移动、拖右下角改大小；自动保存；管理员可「发布」成公共专题看板，全员可见（只读）。
5. 页面看板也能「复制」成专题：改专题不影响原页面，满意后再发布回页面。

**数据集**：订单组、发运明细、波次、每日趋势、**今日订单量/登记覆盖**、人工作业量（按人）、人工作业量（按小时）、**ERP 回传明细（按订单组，可选回传失败/未回传）**、预警清单。
**「今日订单量/登记覆盖」字段**：行数、金额、**已组波行数 / 已组波金额**、**待组波行数 / 待组波金额**、登记覆盖率（都可按线路/库区/区域/单据类型拆分）。
**维度**：线路、区域、库区、单据类型、经销商、波次、发运状态、运输单状态、运输承运商、**ERP 回传状态**、小时、日期、拣货人、复核人、仓库、是否免运费。
**人效指标**：拣货人数/行数/有效小时/人效、复核人数/行数/有效小时/人效（人效 = 行数÷有效小时，行/小时）。

> **所有可配置指标都按行 / 金额 / 比例统计，不再提供"按组"指标**（订单组数、今日订单量(组)、漏登记(组) 等已下线）；
> 订单组本身的明细、台账、存档仍在「订单组登记」页，不受影响。旧看板里若还引用了组指标，会自动回退成"行数"。

## 八、常见问题

**打不开 / 连接被拒**
1. 确认 `启动看板.bat` 窗口还开着（关掉即停服）；2. 本机先试 `http://127.0.0.1:8787`；3. 端口被占用时改 `config.json` 的 `port`；4. 同事访问不了 → 检查防火墙是否放行 8787（跑一次 `安装开机自启.ps1`）。

**双击脚本后窗口一闪就没了 / 页面一直"无法连接"（已修复）**
原因：Windows 批处理必须是 **CRLF 换行 + 纯 ASCII 内容**（不能用 LF、不能混 UTF-8 中文），否则 `cmd.exe` 会把多行命令并成一行，把真正"启动服务"的那条命令吃掉。
现在的 `启动看板.bat` 已按此规范生成（中文提示放在同目录 `banner.txt`，由 `type` 输出），并会在服务真正就绪后才打开浏览器。
如果你自己改过这个脚本，请另存为 **ANSI/ASCII + Windows(CRLF) 换行**，或改回随包提供的版本。

**窗口关掉后想看日志**
`data/server.log`（UTF-8）。服务异常退出时窗口里也会提示。安全起见可把它改成"开机自启"（后台常驻、无窗口）：`安装开机自启.ps1`。

**昨天的登记和今天混在一起 / 新登记跑到昨天（已修复）**
原因：早期默认业务日取"最近一次登记日"，且日期下拉只列已登记过的日期，今天根本选不到，新登记就全落到旧日期。
现在默认业务日 = **系统当天**，下拉一定包含今天（以及已登记/已存档/有数据的日期），选到历史日期会有黄色提示。
对已经错位的登记，可用校正工具按"波次生成时间"自动拆回正确日期（先 dry-run 看）：
```
python tools/dev/fix_registration_dates.py            # 只看会怎么改
python tools/dev/fix_registration_dates.py --apply    # 执行（先备份 + 重建快照/存档）
```

**存档看不到某一天**
只有"存过档"的日期才有快照；历史上已过去的业务日会在跨天后的第一次扫描时自动补档。当天想留档，点「订单组登记 → 存档今日」；数据后来又改了就点「重新存档」（覆盖并留审计）。

**登录失败次数过多**
同一账号连续 5 次密码错误会锁 60 秒；管理员可在「用户与权限 → 重置密码」给临时密码，用户下次登录会被要求改密。

**忘记管理员密码**
停服务，然后执行：
```
python -c "import db,auth; c=db.init_db(); auth.set_password(c,1,'新密码Abc123',0); print('已重置')"
```
（`1` 是管理员账号 id；可在 `data/dashboard.db` 的 users 表确认）

**共享盘 Z: 开机后不可达**
系统会自动改用 `config.json` 里的 `source_dir_fallbacks`（UNC 路径 `\\wanyou\GX1\...`）。如果仍然不通，检查网络与共享权限。

**看板数字和 Excel 对不上**
先看第五节口径；再用 `python ingest.py --check` 复算。常见原因：①波次没登记（不在统计范围）②新导出文件还没落盘 ③经销商映射缺失导致落到「未映射」④某个订单组被「移出」了（在订单组登记页切「已移出」找回）。

**登记波次提示「发运表中没有该波次」**
现在不会再拒绝了：查不到的波次会登记为「待数据」，等 WMS 导出包含它后自动补全。看板顶部会显示当前导出覆盖到哪一天，方便判断是不是文件没更新。

**发布为全员默认后，为什么我同事看到的还是旧布局？**
两种可能：①他打开过页面且系统给过他缓存的个人布局（V5 之前版本），在页面顶部点「切换到公共默认」即可；②他后来自己拖过布局（V5 起会保留个性化，页面顶部会有「公共默认已更新」提示）。
发布只影响**没有个人布局**的人；这是刻意设计，避免覆盖别人调好的看板。

**大屏某些组件只显示一半 / 根本看不到**
v13 已修复：大屏不再直接复用页面的长布局，而是按行自动分页；每个轮播页都完整落在 1920×1080（或 1366×768）内。如果某个看板组件特别多，页数会变多（底部圆点数量=总页数），按 `→` 或等自动轮播即可看到后面的页。

**大屏没有声音**
浏览器规定必须有一次用户交互才允许播放音频：点一下大屏右上角「启用声音」。如果还是没有，检查系统音量与大屏账户权限（需要 `page.screen`）。

**大屏轮播内容不对 / 想换顺序**
大屏右上角「设置」（需 `action.screen.config`）：勾选要播放的看板、填每页秒数。清单顺序按列表顺序轮播。

**人工作业量是空的**
人员字段（拣货人/复核人/组波人）从 **2026-11-03 这次导入** 才开始采集；旧日期没有人员数据是正常的。要有历史数据，把当时的 WMS 导出文件放回 `Z:\单据登记\测试`，在「数据源」点「立即扫描」。

**人效是怎么算的**
人效 = 行数 ÷ 有效作业工时。有效工时 = 该人该工种当天相邻作业时间点的**间隔累加**：间隔 ≤ 阈值（默认 30 分钟）才计入，超过视为休息不计；再扣除全局**休息时段**（默认 12:00-13:00）的重叠分钟。
拣货和复核分开算。阈值与休息时段在「人工作业量 → 作业设置」维护；改完历史存档要「按新口径重新存档全部日期」。
和实际不符时，在「人员明细与工时校正」里填**实际工时**覆盖，点「恢复自动」还原。

**人工作业量的日期和看板日期不一样**
人工作业量按**作业时间日期**归属（拣货看拣货时间、复核看复核时间）；其他看板按业务日期（已登记波次）。同一波次跨天时两边数字会有差异，这是刻意的。

**新增组件时不知道怎么选数据/维度/指标**
点「+ 从模板添加」，按业务分组选场景模板即可（模板已是完整配置）。要自己配就点「按类型自定义」：先选数据集（每个都有说明和适合的图表类型），再选分组与指标（指标按数量/比例/金额/时长分组），ERP 明细等特殊数据集会直接给出“回传失败/未回传”选项，底部会实时预览当前日期的数据条数。

**「未回传明细」之前不显示 / 和回传失败一样**
旧配置弹窗保存时会把 ERP 的筛选清空，导致两个明细组件都按“回传失败”取数。v12 已修复：公共/个人进度页的筛选被自动补回（失败=2 组，未回传=30 组），编辑组件也不会再清空；空数据时会区分“今天没有未回传订单组”和“业务日尚未登记波次”。

**KPI 卡里的数字太小 / 卡片空**
v13 已调整：KPI 卡数字按卡片宽高自动放大（页面约 36–50px，大屏 48–64px）、字重 700，去掉与外卡标题重复的内部小标签，内容垂直居中；表格/图表仍保持原布局，不会改变数据口径。

**为什么组件里没有"订单组数"了**
按你的要求，所有可配置指标都改成按行/金额统计，避免"组数"和"行数"两套口径混着看。订单组明细与台账还在「订单组登记」页（含每日存档），只是不再作为看板指标。

**为什么看板“已登记行数/金额”和“系统订单量”加起来不等于同一天的订单量**
两个口径不同：系统订单量 = **订单日期**是选中日期的全部行；已登记 = 选中日期**已登记波次覆盖的全部行**（含跨天订单、含已移出）。跨天波次会让两者不相等，这是刻意的；页面副标题也写明了。

**ERP 回传状态在哪里看 / 为什么很多“未记录”**
总览页有「回传失败行数/未回传行数」和 ERP 回传状态图；作业进度页底部有「回传失败明细」「未回传明细」两张订单组表。
只有在 WMS 导出包含 ERP 那四列、且该日期数据被重新扫描导入后才有状态；旧文件没有 ERP 列的行会显示「未记录」，不计入失败/未回传。

**自动归档多久跑一次 / 会不会覆盖我手动存的档**
每次扫描（默认 60 秒）发现新增或内容变更时，会覆盖**受影响日期**的快照；没有变化的日期不动。手动「存档/重新存档」仍可用，二者写同一份快照。

**出库文件归档存在哪里 / 为什么只有一个版本**
在 `看板系统/data/outbound_archive/rows.jsonl.gz`：只保存【出库】出库流程节点时间跟踪(配送中心)文件的表头与全部行，**不保存原始 Excel/CSV 表格**；扫描到文件变更时覆盖同一份内容。前端「出库归档」页可按表头筛选、日期区间查询，每页 50 条并导出筛选结果。

**出库归档里有 error 怎么办**
只有写行快照失败（磁盘满/文件被占用）才会记录原因；扫描导入不受影响，下次扫描该文件内容有变化时会自动重试。

**未映射经销商怎么批量补**
数据源页「未映射经销商」→ 导出未映射 CSV → 填好后用 `dealers.xlsx` 批量导入更新。已存在的映射空字段不会覆盖原值；全称必须和发运表一致，否则仍会留在未映射列表里。

**人效存档在哪里**
「人工作业量」右上切「存档」即看当天冻结的汇总；跨天会自动补档（只补缺），手动「存档本日 / 重新存档」可覆盖。

**预警没有发给我**
检查「预警中心 → 线路截止时间与负责人」：该线路负责人里有没有你；或者该线路当天已经复核完成（完成率 100% 不提醒）。没配负责人时会兜底发给管理员。

**订单组号显示「未编号」**
WMS 导出里这几行没填订单组号，系统按 WMS 单号单独成组（避免几百行被并成一个空组）。可以在台账里照常改区域/承运商/指派，不影响存档。

**订单组台账是空的 / 日期选错**
台账只显示"已登记波次"覆盖的数据。先确认「波次登记」里当天有波次；再确认页面顶部的业务日期；若显示「待数据」，说明 WMS 导出还没包含这些波次。

**存档什么时候会自动生成**
跨天后的第一次扫描会把已登记的历史业务日自动补档（只补缺、不覆盖当前那天）。当天想立即留档，点「订单组登记 → 存档今日」；数据后来又变了，点「重新存档」覆盖（会写审计）。

**TMS 里某些波次查不到**
页面会单列"未匹配"，不会算成"未释放"；待数据波次在 TMS 也没有记录时同样显示"-"，属正常。
